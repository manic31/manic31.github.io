개인정보처리방침

시행일: 2026년 11월 7일

「다리 건너 낚시」(manic31.github.io, 이하 ‘사이트’)는 방문자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지키려고 노력합니다. 이 방침은 사이트가 어떤 정보를 다루는지 있는 그대로 알려 드리기 위한 것입니다.

1. 직접 받는 개인정보: 없음

사이트에는 회원가입, 로그인, 댓글, 문의 양식이 없습니다. 이름·전화번호·이메일 같은 개인정보를 직접 받거나 저장하지 않습니다.

2. 사이트를 열 때 자동으로 남는 정보

  • 사이트는 GitHub Pages(GitHub, Inc.)로 운영됩니다. 페이지를 열면 GitHub 서버가 보안과 서비스 운영을 위해 접속 IP 주소 등 접속 기록을 남길 수 있습니다. 운영자는 이 기록을 받아 보거나 쓰지 않습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.
  • 글꼴은 jsDelivr(cdn.jsdelivr.net)에서, 블로그 최근 글의 작은 사진은 네이버(blogthumb.pstatic.net)에서 불러옵니다. 이때 각 서비스에 접속 IP 주소 등이 전달될 수 있습니다.

3. 방문자 기기에만 저장되는 정보

  • 마지막으로 고른 물때 관측소(예: 강화대교)를 다음에 열 때 그대로 보여 드리려고 브라우저 저장공간(localStorage)에 저장합니다.
  • 인터넷이 약한 곳에서도 물때를 볼 수 있도록, 페이지와 물때 자료를 브라우저에 임시 저장(캐시)합니다.
  • 이 정보는 방문자의 기기 안에만 있고 운영자에게 전송되지 않습니다. 브라우저 설정에서 사이트 데이터를 지우면 함께 삭제됩니다.

4. 쿠키

사이트는 현재 쿠키를 사용하지 않습니다.
